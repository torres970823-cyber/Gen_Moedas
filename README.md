

# genMoedas - Conversor Inteligente de Moedas 💱

Projeto em Python desenvolvido para manipulação e conversão de dados monetários em tempo de execução, com suporte a cadastro dinâmico e tratamento de entradas.

## 🚀 Funcionalidades
- Conversão de valores entre diferentes moedas.
- Cadastro dinâmico de novas moedas e taxas durante a execução.
- Tratamento de exceções e validação de dados de entrada.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebook

## 💻 Como Executar
1. Clone este repositório ou abra o arquivo no Google Colab.
2. Execute a célula principal do script Python.
3. Siga as instruções interativas no terminal/console.
